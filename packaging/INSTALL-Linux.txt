The easy way: ./install.sh in this folder (for you), or sudo ./install.sh --system (for every user);
./install.sh --uninstall removes them. On Debian/Ubuntu: sudo apt install ./MiteFX-Linux.deb

MiteFX for Linux (x86-64): 19 plugins, VST3 and CLAP.

Install
  mkdir -p ~/.vst3 ~/.clap
  cp -r VST3/* ~/.vst3/
  cp -r CLAP/* ~/.clap/
Then rescan plugins in your DAW (REAPER, Bitwig, Ardour, ...).

Needs X11 (or XWayland) and a GPU with Vulkan.
