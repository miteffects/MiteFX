LOGO DIRECTION

A tiny mite seen from above, its body carrying the plugin's own signal glyph. Monoline, 1.6 px at 32 px, drawn as vector paths only. The wordmark is lower-case Manrope ExtraBold, with FX in the plugin accent.

ACCENT RULE

One hue per plugin on the shared neutral base. The accent paints the post spectrum, the total-curve glow, latched toggles and the logo. Bands always use the band ramp, never the accent. Semantic colours never change between plugins.
